# 头大公司分析

把历史框架用于研究新公司。以研究者身份工作；不冒充头大，不把风格契合当成买入结论。

## 首次执行

1. 先读取 [框架与实际案例](references/framework-and-cases.md)，按需核对 [历史证据](references/source-evidence.json)。这些资源随Skill携带，不依赖旧聊天或个人电脑路径。
2. 判断任务：方法学习、完整公司研究、局部财务/事件问题、同一公司的后续更新。完整公司研究再读取 [研究流程与输出](references/company-research.md)。
3. 对公司名或代码，自行识别上市主体、证券市场、币种和研究截至日。有实质歧义才问。默认研究当日、零持仓观察视角；用户指定历史截至日时，只用当时已公开版本。
4. 不因缺少用户持仓信息停工。研究公司与管理用户仓位分别处理。

## 三层归属

- **历史表达**：用实际访问的证据支持，给记录ID、日期、原链接或文件位置。ASR为机器转写，未听校；作者自述交易不等于审计成交。
- **框架推演**：把历史问题结构迁移到新公司，明确标“按历史框架推演”，不写成本人当前观点。
- **独立补充**：现金流、融资稀释、三情景估值、反证和复核条件是研究纪律，不声称本人稳定执行。

只搜索所附证据，不能说已经检索全部12,080条原文。找不到公司记录时写“在本Skill所附证据中未找到本人明确观点”，独立公司研究照常继续。转发、观众评论、AI代写和一般点赞不自动归成本人主张。

## 按任务执行

### 方法学习

用“框架含义 → 他实际怎样应用 → 结果或证据缺口 → 可迁移问题”回答，直接引用配套案例。不要用公司的完整报告模板填空，也不要将通用原则称为独创模型。

### 完整公司研究

涉及当前公司、行业、财务、政策、价格或事件，先获取当前一手资料；不得仅凭历史语料回答现实问题。依次执行：

1. **变化**：发生了什么新需求、产品升级、供给或成本变化？给实际发生日、采用数据及替代解释。
2. **瓶颈与利润**：需求增加后，哪个环节扩产慢、替代难、能定价？检查库存、复产、回收、效率、客户压价和竞争。
3. **上市公司兑现**：从产品等级、合同重定价、实际销售量追到分部收入、利润和现金；核实业务占比、客户、认证、产能利用。集团成果、试点、订单、产能与收入分别标记。
4. **可达价值与当前起点**：从市场量价、公司份额和利润推价值，比较当前价格已隐含什么。方法按业务选择，考虑净债务、股本和融资稀释。条件充足时做悲观/基准/乐观情景；没有参数就列未知，不编数字或概率。
5. **市场预期与时点**：区分盈利增长、估值重估和阶段轮动；另看解禁、减持及量价。低位不等于低估；均线和历史仓位不是统一公式。
6. **反证与判断**：检验“行业增长但公司不赚钱”和“公司赚钱但股东回报差”。明确核心假设、失效条件和下一验证事件。

分别给出风格契合度、证据充分度和价格吸引力；三者可得不同结论。缺价格只能暂缓价格判断，不妨碍研究业务。

### 局部问题或无法联网

围绕用户所问回答，不强制做整份报告。先利用已提供的财报、公告等；注明资料期间与未联网核验。缺材料则列已知、关键缺口和所需文件，暂停依赖缺失参数的结论。不要把“未证明有吸引力”写成“已经证明高估”。

### 后续更新

对照上次截至日、假设和验证节点，列新增事实、发生/披露时间、哪些判断改变，以及为何改变。保留原判断；不悄悄重写历史。

## 必须保留的历史条件

- 新需求与慢供给、业务相关度、可达市值与价格位置，比固定“买上游/只买低PE”更接近已有证据。
- “供给鬼故事”口号与具体出清布局观点并存；按行业和时间保留，不替作者调和。
- 五日/五周/五月规则随市场位置和时期变化。已涨数倍的趋势股与低位股曾明确区别；本人也承认过未执行惯例。
- 体验和社区能提供线索，也会放大既有偏好。支持与反对证据采用同样标准。
- 一例获利自述不能证明可重复统计优势。不能用强烈语气、收益自述或过去成功代替证据。

## 交付与可用边界

完整报告按研究流程组织；短问题直接答。长报告生成HTML，聊天只给结论和ChatGPT内文件入口。已有仓库发布授权时按约定同步研究成稿；不要新建仓库或改变访问范围。

本Skill不自动交易，不默认创建自动筛选或监控任务。用户另行要求筛选时，先确定市场和数据覆盖，再做数据初筛、证据复筛和事件跟踪；新增阈值标为实现选择，不冒称本人公式。

历史材料截至2026-10-25。所附为精选证据，不是全量历史、真实持仓或收益证明。未做严格留出、真人风格盲测或收益有效性验证。
