# 思维框架与实际案例

## 使用口径

以下是从历史原文重建的问题结构，不是本人认证、独创或始终执行的算法。证据编号TDxx对应同目录source-evidence.json；原文只能证明当时表达，不能证明产业事实或账户收益。视频为ASR，日期可为上传/场次代理。

## 1. 新需求与慢供给的错位

**问题结构**：终端产品变化 → 需求增量 → 各环节供给响应速度 → 量价与利润归属。

**实际应用：锂矿（2021）**。作者用下游销量超预期、中游扩产快、矿山建设慢解释上游约束，随后补充锂最终会够用，但扩产需要时间；又强调涨后没有建议追入之意。证据TD01、TD02、TD03。

**实际应用：小金属（2023）**。要求未来产业中有大额且增加的用量，并看相关业务占上市公司营收的大小。行业重要不等于任何相关公司都高弹性。证据TD04。

**边界和反例**：2025要求新需求、反对容易回来的退出供给，却在磷酸铁上又采用亏损出清逻辑。没有统一判别式，不能写成“供给分析永远无用”。证据TD05、TD06、TD07。

**迁移到新公司**：问增量规模、供给时滞、复产与替代、议价权，以及目标业务是否足以影响整体利润；新增现金与融资检验是研究者补充。

## 2. 利润传导必须落到公司

**问题结构**：产品等级 → 现货/长协 → 合同重定价 → 实际销售量 → 上市公司业绩。

**实际应用：氦气（2026-09-04）**。作者区分粗氦和高纯、现货和长协，认为高价要持续才可能传到合同；随后明确未知的是合同和产量。用该问题结构理解机制，不将文中气价或政策当成当前事实。证据TD08、TD09。

**边界**：提出了正确的检查问题，不等于关键参数已经闭合；时代参与感解释持有动机，不能填补合同、产量和现金数据。

**迁移到新公司**：量价情景先核对业务占比、实现售价、交付和回款；关键数据未知则明确待验证，不能把总市场想象计为公司利润。

## 3. 可达市值与当前起点共同决定机会

**问题结构**：未来市场 → 公司地位/份额 → 可得利润 → 潜在市值 → 今天价格尚有多少空间。

**实际应用：估值回答（2022）**。作者说主要看市值，并依次谈行业空间、公司领导地位、合理利润和潜在市值。不是只看PE。证据TD10。

**实际应用：2024方法表达**。同一图文既强调K线权重，又要求看基本面和景气度、拉Excel算账。其“50%”是该次措辞，不冻结为永远有效的权重。证据TD11。

**实际应用：呷哺（2021）**。面对消费体验异议，以自己的到店经历、扩店与相对市值保留看法，同时承认远期路径想不清。这暴露对愿景与路径未知的宽容，不是估值已获验证。证据TD12。

**迁移到新公司**：三情景、股本/净债务、融资稀释、现金消耗和反向估值是为使用者补充的纪律；不能声称头大原本完整执行过这套程序。

## 4. 经营与市场预期存在时间差

**问题结构**：产业变化、财报兑现和股票行情不一定同步；先明确正在交易哪一种变化。

**实际应用**：早期评论区分长期公司判断与短期题材；2026AI医疗发言接受情绪与业绩两种路径，又说更大产业行情需业绩衔接。证据TD13、TD14、TD20。

**边界**：若无法预先说清情绪何时交接业绩，解释就可能事后切换；不能把“财报尚未好”自动写成好机会。

## 5. 执行规则有场景，认知不等于行动

**实际应用：均线退出（2021）**。作者给分层减仓口径，追问后又限定低位股不适用，并指向已经涨数倍、趋势走出的股票。证据TD15、TD16、TD17。

**实际应用：2026-10-23复盘**。他否认单纯忙碌导致未退出，承认太在意、入戏太深、没有遵守惯例，并反思仓位风格趋同。该自述不能回填成之前实际执行过止盈。证据TD18。

**迁移到新公司**：分开方向、估值、资金与动作；不复制8%仓、6.18%缓冲或某条均线为统一参数。没有完整流水，不计算其收益或回撤。

## 6. 表达方式与证据标准

用直观类比、短段、自问自答解释机制；不复制绝对预测、群体动员或恶意化异议。

技术分析争论里，观众在问稳定有效是否有统计证据，作者用自己的获利特例反驳完全无用；两者命题不同，一例获利不能证明稳定优势。证据TD19。

## 使用示例

- “按头大框架分析这家公司”：从变化、瓶颈、利润、价格和预期入手，再查当前公司资料，不替本人表态。
- “他如何分析氦气”：按案例2还原其传导问题与未知参数，不混入当前荐股。
- “跌破五周线是不是卖”：用案例5解释条件与版本，不给无条件清仓口令。
